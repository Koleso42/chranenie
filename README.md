# Хранение шин по регионам

Источник: https://koleso-tire-storage-regions.stonyrose8.chatgpt.site/

GitHub-копия: https://koleso42.github.io/chranenie/?view=1&tab=compare
Адрес заработает после включения Pages и успешного deploy.

## Публикация
Settings → Pages → Source: GitHub Actions.
Для приватного репозитория GitHub Pages требует подходящего платного плана GitHub.
Сайт Pages обычно публичный даже при приватном репозитории. Видимость репозитория эта настройка не меняет.
После включения Pages: Actions → Refresh and publish dashboard → Run workflow.

## Обновление
Существующее задание ChatGPT «Обновление хранения шин» запускается ежедневно в 08:00 Europe/Moscow.
После проверки цен и публикации исходного сайта оно меняет refresh-request.json.
Workflow экспортирует страницу и данные в docs, сохраняет коммит и публикует новую версию по прежней ссылке.
Сам экспорт не перепроверяет цены и не меняет даты подтверждения данных.
Ручное обновление: Actions → Refresh and publish dashboard → Run workflow.

## Проверки
Экспорт отклоняет пустые тарифы и несовпадение версии страницы с версией snapshot/head.
Снимок сохраняется отдельно, загружается относительно страницы и без браузерного кеширования.
Статическая копия открывается в режиме просмотра; облачное редактирование остаётся в исходном сайте.
Исходная публичная версия от 27.10.2026 содержит 4488 тарифных записей.
